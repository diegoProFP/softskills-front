Concepto base

Que es una soft skill en esta aplicacion

Una soft skill es una competencia transversal que se observa en el comportamiento del alumno. No se evalua solo con examenes: se mide a partir de evidencias registradas durante el trabajo diario.

Ejemplo positivo

Si un alumno ayuda a resolver una duda del grupo, puede registrarse como una muestra positiva de Participacion.

Ejemplo negativo

Si un alumno permanece bloqueado mucho tiempo sin pedir ayuda ni consultar recursos, puede registrarse como una muestra negativa de Autonomia.
